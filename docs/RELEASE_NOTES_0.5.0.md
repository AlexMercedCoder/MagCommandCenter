# Mag Command Center 0.5.0

Mag Command Center 0.5.0 completes Graph Board as a daily-driver visual authoring and durable execution workspace for Agentic Graph Specification 1.0.

Highlights include all-node templates, schema-driven editing, safe rename and duplication, OAP authority review, filters and bulk editing, accessible dependency mapping, YAML/JSON source and diff views, recoverable drafts, external-file conflict handling, deterministic and planning-model generation, reviewable graph proposals, trusted plugin templates, digest-bound plans, selective gates, a fixed To do / Current work / Done board, terminal job summaries, reconnectable live card state, and durable pause, cancellation, resume, and per-card retry-with-dependents controls.

This release requires MagAgent 0.96.0 and the `magent.agentic-graph-authoring.v2`, `magent.graph-plan.v2`, `magent.graph-event.v1`, and `magent.graph-status.v1` contracts. Cross-platform installers remain subject to the native release workflow and signing gates.
